# CGPA Calculator

A simple and user-friendly web-based CGPA Calculator.

The application allows students to enter their subjects, credits, and grades and automatically calculates their CGPA.

## Features

- Add multiple subjects
- Enter subject name and credits
- Select grades from a predefined grade scale
- Calculate CGPA automatically
- Display total credits
- Validate credit values
- Simple and responsive user interface
- No backend or database required

## Grade Scale

| Grade | Grade Point |
| --- | ---: |
| A+ | 10 |
| A | 9 |
| B+ | 8 |
| B | 7 |
| C | 6 |
| D | 5 |
| F | 0 |

The CGPA is calculated using:
